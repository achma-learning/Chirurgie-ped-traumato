## Modèles de notes

- **POTEC Basique (image)** : champs *Front, Back, Extra (commentaire), Source* — supporte les radiographies.
- **POTEC Cloze** : champs *Text, Extra, Source* — occlusion `{{c1::…}}`.

Style CSS commun (vignette encadrée, réponse surlignée, images responsives).

## Conseils d'étude

- Filtrer par `Topic::Supracondylienne`, `Topic::DecollementEpiphysaire`, `SalterHarris`… pour réviser un thème.
- Combiner `BoardReview` + une région pour une révision ciblée avant examen.
- Les paquets *Notions de base* / *Synthèse haut rendement* constituent le socle théorique : à voir en premier.
